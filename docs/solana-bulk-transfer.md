# Solana Bulk Transfer

Solana bulk transfer refers to sending SOL or supported SPL tokens to multiple wallet addresses.

## What Is Solana Bulk Transfer?

Instead of processing transfers individually, a bulk transfer workflow can organize multiple recipients into a single operational process.

## Common Use Cases

Solana bulk transfers can be useful for:

- Web3 applications
- Testing
- Airdrop management
- Treasury operations
- Payment distribution
- Operational wallet management

## SOL Bulk Transfer

SOL can be transferred between Solana addresses.

Before sending funds, always verify recipient addresses and transaction details.

## SPL Token Bulk Transfer

SPL tokens can also be transferred between compatible Solana token accounts.

The exact transaction structure depends on the token and token program being used.
