# Solana Wallet Security

Solana wallet security is important when managing SOL, SPL tokens and multiple operational wallets.

## Protect Private Keys

Private keys should never be published or shared.

Do not store private keys in:

- GitHub repositories
- Public issue trackers
- Chat messages
- Screenshots
- Public logs

## Check Wallet Activity

Public blockchain data can be used to inspect wallet activity and transactions.

## Check Token Accounts

Solana wallets may interact with multiple token accounts.

Reviewing token accounts can help users understand assets associated with an address.

## Token Authorities

Some Solana tokens can have authority configurations that affect how the token behaves.

Users should understand the token's configuration before interacting with unknown assets.

## Suspicious Transactions

When investigating an unfamiliar transaction, review:

- Transaction signature
- Accounts
- Instructions
- Programs
- Token transfers
- Destination addresses
