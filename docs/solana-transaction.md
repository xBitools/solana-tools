# Solana Transaction

A Solana transaction contains instructions that interact with accounts and programs on the Solana blockchain.

## Solana Transaction Signature

A transaction signature can be used to identify a transaction.

## Solana Transaction Instructions

Instructions describe operations performed by programs during transaction execution.

## Solana Transaction Accounts

Transactions reference accounts involved in the operation.

## SOL Transfer

A SOL transfer moves the native Solana asset between addresses.

## SPL Token Transfer

An SPL token transfer interacts with token accounts and the relevant token program.

## How to Check a Solana Transaction

A transaction can be inspected using its transaction signature and Solana blockchain data.

## How to Decode a Solana Transaction

Transaction decoding involves inspecting instructions, accounts, programs and relevant data.
