# Solana Wallet Sweeper

A Solana wallet sweeper is a tool or workflow designed to consolidate assets from multiple wallets into a destination wallet.

## What Is Solana Wallet Sweeping?

Wallet sweeping generally means moving eligible assets from one or more operational wallets into another wallet.

## Solana Wallet Consolidation

Wallet consolidation can help organize assets distributed across multiple addresses.

Common use cases include:

- Wallet management
- Treasury organization
- Operational wallet cleanup
- Development environments
- Asset consolidation

## SOL Sweeping

SOL can be moved from eligible source wallets to a destination address.

Transaction fees and account requirements should be considered before performing transfers.

## SPL Token Sweeping

SPL token consolidation may involve token accounts and associated account requirements.

The exact implementation depends on the token and token program.
