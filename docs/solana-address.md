# Solana Address

A Solana address identifies an account or address on the Solana blockchain.

## What Is a Solana Address?

Solana addresses are used to receive assets and interact with blockchain applications.

## Solana Wallet Address

A wallet address can be shared publicly when receiving SOL or supported tokens.

## Check a Solana Address

Public blockchain information can be used to inspect an address.

Information may include:

- SOL balance
- Token accounts
- Token balances
- Transaction history
- Account activity
