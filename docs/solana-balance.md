# Solana Balance Checker

A Solana balance checker allows users to inspect SOL and token balances associated with Solana addresses.

## Check a Solana Wallet Balance

A Solana wallet balance can be queried from the blockchain using an RPC endpoint or blockchain data service.

## Check Multiple Solana Wallet Balances

When managing multiple wallets, checking balances one address at a time can be inefficient.

A batch balance workflow can help users inspect multiple addresses more efficiently.

## SOL Balance

SOL is the native asset of the Solana blockchain.

## SPL Token Balance

SPL token balances are associated with token accounts belonging to wallet addresses.

## Solana Balance Checker Tool

Bitools provides Solana balance tools for checking wallet and token balances.

https://bitools.pro/solana/

## Security

A balance checker should only require public blockchain information.

Never provide private keys or recovery phrases to a balance checking service.
