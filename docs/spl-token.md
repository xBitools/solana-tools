# SPL Token

SPL Token is the token standard and token infrastructure used by tokens on Solana.

## What Is an SPL Token?

SPL tokens are digital assets issued on the Solana blockchain.

## SPL Token Address

A token mint address identifies a specific token.

Always verify the mint address before interacting with a token.

## SPL Token Balance

A wallet can hold SPL tokens through token accounts.

## SPL Token Holders

Token holder information can be analyzed using public blockchain data and supported blockchain APIs.

## SPL Token Transfer

SPL tokens can be transferred between compatible token accounts.

## SPL Token Tools

Bitools provides tools and resources for inspecting Solana and SPL token information.
