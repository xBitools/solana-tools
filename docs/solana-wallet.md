# Solana Wallet

A Solana wallet allows users to manage SOL, SPL tokens and interact with applications on the Solana blockchain.

## What Is a Solana Wallet?

A Solana wallet is used to manage blockchain accounts and interact with Solana applications.

A wallet generally provides an address that can receive SOL and supported tokens.

## Solana Wallet Address

A Solana wallet address is a public identifier that can be used to receive assets and inspect blockchain activity.

Never share private keys or recovery phrases publicly.

## How to Create a Solana Wallet

A Solana wallet can be created using compatible wallet software or programmatically using Solana development libraries.

For development and testing, developers can also generate wallets using code.

## Multiple Solana Wallets

Users and developers may need multiple Solana wallets for:

- Development
- Testing
- Asset organization
- Separate operational accounts
- Application testing

## Solana Wallet Security

Private keys and recovery phrases should always be protected.

Do not publish private keys in GitHub repositories, issues, logs or public documentation.
